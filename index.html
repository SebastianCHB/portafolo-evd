Esquema de Base de Datos

Arquitectura estructurada y dividida por módulos para mayor claridad.

1. Usuarios y Estructura Organizacional

Controla los usuarios del sistema, a qué áreas pertenecen y sus grupos de trabajo.

Módulo Usuarios (Usa el scroll para hacer zoom)
erDiagram users { bigint id PK string nombre string email UK bigint area_proceso_id FK } areas { bigint id PK string nombre bigint responsable_id FK } grupos_trabajo { bigint id PK string nombre UK } usuario_grupo { bigint user_id PK, FK bigint grupo_id PK, FK boolean can_ver } users }|--|| areas : "Pertenece a (area_proceso_id)" areas }|--|| users : "Tiene un responsable" usuario_grupo }|--|| users : "user_id" usuario_grupo }|--|| grupos_trabajo : "grupo_id"
Tabla Descripción
users Almacena los usuarios del sistema, credenciales y flags de permisos generales.
areas Departamentos o áreas organizativas con reglas de edición.
grupos_trabajo Catálogo para agrupar usuarios bajo un rol colectivo.
usuario_grupo Asocia a un usuario con uno o más grupos, guardando permisos específicos.

2. Gestión Documental (Bóvedas y Fichas)

El núcleo de la aplicación: el almacenamiento lógico de documentos (Bóvedas), su tipología y las Fichas (los documentos per sé).

Módulo Documental
erDiagram bovedas { bigint id PK string nombre UK bigint boveda_siguiente_id FK bigint responsable_id FK } tipos_ficha { bigint id PK string nombre UK string familia } fichas { bigint id PK bigint tipo_ficha_id FK bigint user_id FK bigint boveda_id FK string clave string titulo } tipo_ficha_grupo { bigint tipo_ficha_id PK, FK bigint grupo_id PK, FK } tipo_ficha_boveda { bigint tipo_ficha_id PK, FK bigint boveda_id PK, FK } bovedas }|--|o bovedas : "Secuencia (boveda_siguiente)" fichas }|--|| tipos_ficha : "Es de tipo" fichas }|--|| bovedas : "Almacenada en" tipo_ficha_grupo }|--|| tipos_ficha : "tipo_ficha" tipo_ficha_boveda }|--|| tipos_ficha : "tipo_ficha" tipo_ficha_boveda }|--|| bovedas : "boveda"
Tabla Descripción
bovedas Contenedores lógicos de fichas con reglas visuales y de flujo (secuencias).
tipos_ficha Catálogo de configuraciones de formulario (ej. Procedimientos, Manuales) con esquema JSON.
fichas El registro documental principal. Vincula a un usuario, a una bóveda y a un tipo de ficha.

3. Seguridad Avanzada

Control granular (Matriz Triple) que define qué puede hacer exactamente un Usuario, actuando bajo un Grupo, dentro de una Bóveda específica.

Módulo Seguridad
erDiagram perfiles_seguridad { bigint user_id PK, FK bigint grupo_id PK, FK bigint boveda_id PK, FK boolean can_ver boolean can_registrar boolean can_actualizar } users { bigint id PK } grupos_trabajo { bigint id PK } bovedas { bigint id PK } perfiles_seguridad }|--|| users : "Usuario asignado" perfiles_seguridad }|--|| grupos_trabajo : "En representación del Grupo" perfiles_seguridad }|--|| bovedas : "Sobre esta Bóveda"
Tabla Descripción
perfiles_seguridad Establece permisos específicos de lectura, escritura o actualización uniendo 3 variables: Usuario, Grupo y Bóveda.

4. Foliación Automática

Administración de contadores (folios) y a qué elementos están vinculados.

Módulo Foliación
erDiagram foliadores { bigint id PK string nombre UK string prefijo string sufijo int comienza_en } foliador_tipo_ficha { bigint foliador_id PK, FK bigint tipo_ficha_id PK, FK } foliador_grupo { bigint foliador_id PK, FK bigint grupo_id PK, FK } foliador_tipo_ficha }|--|| foliadores : "foliador_id" foliador_grupo }|--|| foliadores : "foliador_id"
Tabla Descripción
foliadores Lleva el conteo de los números de registro, secuencias, prefijos y pasos.
foliador_tipo_ficha Tabla pivote para vincular un foliador a un tipo de ficha específico.
foliador_grupo Tabla pivote para asignar un foliador a un grupo de trabajo.
