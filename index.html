Sobre mí

Tengo 21 años, soy egresado del ITSNCG en Ingeniería en Sistemas Computacionales. Me defino como una persona tranquila pero con una mente que nunca deja de trabajar. Para mí, la ingeniería no es solo código — es una forma de entender cómo funciona el mundo.


Ilustración y Dibujo: Desde pequeño el dibujo ha sido mi refugio creativo. Ilustrar me enseñó a observar los detalles, algo que aplico directamente al desarrollo de software para crear interfaces con alma y equilibrio visual.


Curiosidad Infinita: Soy lector apasionado y entusiasta del aprendizaje autodidacta. Creo que la mejor habilidad de un ingeniero es saber aprender. Cuando no estoy frente a un monitor me encontrarás en los libros o en la cancha.

Zoocial

Ecosistema Social Multiplataforma

Plataforma híbrida (Web y Móvil) para la comunidad de rescate animal. Diseñada para conectar refugios, adoptantes y veterinarios en un solo ecosistema.

  • Desarrollo multiplataforma con React (Web) y Jetpack Compose (Android)
  • Integración de APIs para gestión de usuarios, perfiles de mascotas y servicios veterinarios en tiempo real
  • Arquitectura escalable con Laravel como API REST central
  • Interfaces centradas en el usuario (UX/UI) con flujos de interacción para reporte y adopción de mascotas
  • Sistema de adopciones con filtros por especie, estado y disponibilidad
